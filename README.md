# 任嘉伦新剧《无忧渡》宣传网页

## 项目简介

这是一个关于任嘉伦主演的新剧《无忧渡》的宣传网页项目。该网页采用了清新主义美学设计风格，展示了《无忧渡》电视剧的全方位信息，包括基本信息、创作团队、演员阵容、剧情简介、艺术特色、幕后花絮、观众反响和市场表现等内容。

## 文件结构

- `index.html` - 网页的HTML结构
- `styles.css` - 网页的CSS样式表
- `script.js` - 网页的JavaScript交互脚本
- `xuanchuan.md` - 原始内容Markdown文件
- `README.md` - 项目说明文档

## 设计风格

本项目遵循以下设计风格原则：

1. **优雅的清新主义美学** - 整体设计简洁、清爽，避免复杂和繁琐的元素
2. **清新柔和的渐变配色** - 使用柔和的蓝紫色渐变作为主色调，搭配白色背景增强清新感
3. **恰到好处的留白设计** - 各元素之间保持适当的间距，提高可读性和视觉舒适度
4. **信息层级通过微妙的阴影过渡** - 使用轻微的阴影效果区分不同内容区块
5. **用户视线自然聚焦核心功能** - 重要信息突出显示，引导用户视线流动
6. **精心打磨的细节** - 包括圆角、微交互、视觉比例和规范的间距等

## 功能特点

1. **响应式设计** - 适配不同屏幕尺寸的设备
2. **平滑滚动导航** - 点击导航链接平滑滚动到对应部分
3. **滚动监听** - 根据当前浏览位置高亮对应的导航项
4. **数字动画** - 统计数据采用动画效果展示
5. **渐入效果** - 页面元素随着滚动逐渐显示
6. **交互反馈** - 卡片元素在鼠标悬停时有轻微的上浮效果

## 如何使用

1. 在浏览器中打开`index.html`文件即可查看网页
2. 通过顶部导航栏可以快速跳转到不同内容区域
3. 滚动页面查看所有关于《无忧渡》的详细信息

## 自定义修改

如需修改网页内容或样式：

- 编辑`index.html`文件可更改网页结构和内容
- 编辑`styles.css`文件可调整网页样式
- 编辑`script.js`文件可修改交互效果

## 注意事项

- 当前网页中的演员图片使用了占位图，实际使用时应替换为真实图片
- 为获得最佳视觉效果，建议使用现代浏览器（如Chrome、Firefox、Edge等）
- 网页中的数据基于2025年4月14日的信息，后续可能需要更新
